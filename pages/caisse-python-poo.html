Application - Ticket de caisse

Python POO

Application de gestion de caisse

Projet de démonstration de Programmation Orientée Objet en Python avec persistance SQLite.

Fonctionnalités :

  • Architecture modulaire (Entités, Composants, Data, Affichage)
  • Gestion des tickets avec calcul automatique des totaux
  • Sauvegarde des ventes dans SQLite
  • Affichage d'un ticket formaté en console

Structure du Projet :

  • main.py : point d'entrée principal de l'application
  • /entites : modèles de données (Produit, Vendeur, Categorie)
  • /composants : logique métier (Ticket, LigneTicket)
  • /data : gestionnaire de base de données
  • /affichage : formatage visuel du ticket
