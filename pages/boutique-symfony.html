Application Symfony - E-commerce

E-commerce

Application web e-commerce complète développée avec le framework Symfony.

Projet de démonstration mettant en œuvre la conception d’une application web structurée, avec intégration front-end, logique métier back-end et gestion de base de données.

Fonctionnalités :

  • Catalogue de produits avec affichage dynamique
  • Fiche produit détaillée
  • Ajout / suppression de produits dans le panieri>Sauvegarde des ventes dans SQLite
  • Calcul automatique du total du panier
  • Gestion du tunnel de commande
  • Interface responsive avec Bootstrap
  • Interaction dynamique avec JavaScript

Architecture du Projet :

  • Symfony : gestion de l’application et de la logique métier
  • Controllers : gestion des routes et du flux applicatif
  • Entities : modélisation des données (Produit, Commande, Utilisateur…)
  • Repositories : accès et requêtes base de données
  • Templates Twig : rendu des pages côté front-end
  • Assets : gestion CSS / JavaScript
  • Base de données : persistance des données utilisateurs et commandes

Structure du Projet :

  • /src/Controller : gestion des routes et logique applicative
  • /src/Entity : modèles de données (produits, commandes…)
  • /src/Repository : accès aux données
  • /templates : templates Twig pour l’affichage
  • /public : ressources publiques (CSS, JS, images)
  • /config : configuration de l’application

Technologies utilisées :

  • PHP
  • HTML5
  • CSS3
  • Bootstrap
  • JavaScript
  • MySQL / MariaDB

Compétences mises en œuvre :

  • Conception d’une application web avec Symfony
  • Structuration d’un projet MVC
  • Intégration front-end responsive
  • Gestion des interactions utilisateur
  • Connexion et manipulation de base de données
  • Mise en place d’un tunnel de commande e-commerce
