Analyse de données

Projet d' analyse de données commerciales fictives inspirées du secteur dermo-cosmétique.

Projet réalisé en Python dans le but de manipuler, analyser et visualiser des données liées aux ventes, à la satisfaction client et aux performances commerciales.
Projet documenté en anglais afin répondre aux standards de collaboration internationaux du secteur Data.

Compétences mises en œuvre:

  • Analyse de données avec Pandas
  • Data visualisation avec Plotly
  • Manipulation de fichiers CSV
  • Nettoyage de données
  • Structuration et exploitation de données
  • Logique métier
  • Python orienté analyse

Structure du Projet:

  • main.py : point d'entrée principal de l'application
  • /data : modèles de données (CSV)
  • /graphs : fichiers .html pour la création des graphiques
  • /screenshots : captures d'écran des graphiques
